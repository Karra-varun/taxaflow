# Global Tax Flow

🚀 MASTER PROMPT FOR AI APP BUILDER

1. Product Overview

Product Name: TaxaFlow

Tagline: Get paid globally. Stay compliant locally.

Target Audience:
Freelance creators and remote workers in Southeast Asia (India, Indonesia, Philippines, Vietnam) who receive international payments via platforms like PayPal, Stripe, Upwork, and Fiverr.

Problem it solves:
Freelancers struggle to track global income, convert currencies, and understand local tax obligations. Existing solutions are either too manual (spreadsheets) or too complex (accountants and enterprise tools). TaxaFlow simplifies this with an AI-powered dashboard and tax summaries.

2. Core Features (MVP Focused)

Payment Tracking Dashboard
